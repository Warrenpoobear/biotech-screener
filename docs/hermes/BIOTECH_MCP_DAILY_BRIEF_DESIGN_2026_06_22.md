# Biotech-MCP Daily State Brief — Design (2026-06-22)

**Status:** `DESIGN_ONLY — CRON_NOT_REGISTERED`
**Branch:** `biotech-mcp-daily-briefs-2026-06-22`
**MCP dependency:** `biotech` server registered in `~/.hermes/config.yaml` (Package C2, 2026-06-22)

---

## Purpose

A daily read-only brief covering six areas of platform state, produced by a Hermes agent
using only the 11 registered `biotech` MCP tools plus read-only shell commands.

No production writes. No git operations. No auto-fixes. Output is a Markdown file at
`artifacts/daily_briefs/BRIEF_<date>.md` for operator review.

---

## Six-section brief format

| # | Section | Primary tool(s) | Key questions |
|---|---|---|---|
| 1 | Production snapshot | `run_readonly_diagnostics`, `read_latest_snapshot_manifest` | Latest snapshot date, artifact completeness, staleness |
| 2 | Phase 2 health | `read_phase2_health` | Gate verdicts (Drawdown/IC/Jaccard/Emergency), any breaches |
| 3 | Gate verdict drift | `read_gate_verdicts` | Last 5 verdicts, direction of change, any new fails |
| 4 | Scientific Cartography | `read_scientific_cartography_status`, `list_disease_map_artifacts` | Latest run date, errors/warnings, artifact completeness |
| 5 | Platform posture | shell only (no MCP) | Hermes gateway health, harvester state, OpenClaw state, PR queue |
| 6 | Governance blockers | `read_semgrep_findings`, shell | Open PRs needing review, Semgrep MCP B1–B4, unresolved decisions |

---

## Output path

```
artifacts/daily_briefs/BRIEF_YYYY-MM-DD.md
```

`artifacts/daily_briefs/` is gitignored by default (not committed automatically).
Operator may `git add` and commit a brief as a dated record if desired.

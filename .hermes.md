# Biotech Screener Project

Hermes: when working in this repo, follow these rules.

## Architecture
- MCP server (`mcp_server.py`) exposes 8 tools via stdio, registered in Hermes config.yaml
- Web app (`web/app.py`) — FastAPI dashboard on port 8000
- Score optimizer — IC 0.0623, ensemble runner
- 5 cron jobs (daily refresh, weekly briefing, catalyst intel, webhook monitor, daily briefing)
- Webhook receiver for external event triggers

## Commands
- Launch dashboard: `uvicorn web.app:app --port 8000 --reload`
- MCP tools: `mcp_biotech_screener_*` (8 tools)
- Pre-commit is strict — use `--no-verify` to bypass when needed

## Conventions
- Use the project `.venv` (not system Python) for all runs
- MCP server env: `BIOTECH_PROJECT_DIR` must point to this directory
- Cron jobs use `workdir: C:\Projects\biotech_screener\biotech-screener` — keep this stable
- Biotech MCP tools available: `screen_universe`, `get_company_detail`, `get_clinical_trials`, `get_catalysts`, `get_backtest`, `compare_snapshots`, `get_atlas_data`, `get_universe`

## Data Flow
- Clinical trials: AACT database → screener → scores → snapshots → backtest
- Cron jobs refresh data, generate briefings, monitor catalysts
- Webhook receiver handles external payloads → triggers agent runs

## Pitfalls
- Nested directory: `biotech_screener/biotech-screener/` — always cd into the inner dir
- Windows paths: use forward slashes in code, `C:\` in config
- Pre-commit hooks include ruff, flake8, mypy, semgrep, secret detection
